# Lab HTTPS certificates

Generated by `scripts/generate-lab-https-certs.sh`.

- **Committed:** nothing secret. Private keys stay local under this folder (gitignored).
- **DPC:** public `ca.crt` is copied to `apps/android-dpc/app/src/main/res/raw/mip_lab_ca.crt` so the agent can trust lab TLS without installing a user CA.
- **Backend:** set `TLS_CERT_PATH`, `TLS_KEY_PATH`, and `HTTPS_PORT` (default `3443`). HTTP on `PORT` remains for Merchant Web / adb reverse.

Not for production. Rotate by re-running the script when the LAN IP changes.
